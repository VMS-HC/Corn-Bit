## :toolbox: Getting Started

### :bangbang: Prerequisites

- KICAD!!!<a href="kicad.org"> Here</a>
```bash
 xdg-open https:kicad.org
```


### :gear: Installation

Follow the KICAD install guide and then download the project's files (name.kicad_sch, name.kicad_pcb, name.kicad_pro)!
```bash
sudo add-apt-repository --yes ppa:kicad/kicad-10.0-releases sudo apt update sudo apt install --install-recommends kicad
```


### :running: Run Locally

Clone the project

```bash
https://github.com/VMS-HC/Corn-Bit
```
Duel Attiny412 dev/processing board!
```bash
cd ~/corn-bit
```
