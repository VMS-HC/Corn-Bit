# Contributing to Corn Bit

Thank you for your interest in contributing to Corn Bit! This document provides guidelines and steps for contributing.

## How to Contribute

Open a PR and add anything as long as it doesn't degrade the project or community! Thanks!

Kicad!

## Pull Request Process

1. Fork the repository and create your branch from `main`.
2. Make your changes and ensure tests pass.
3. Update documentation if needed.
4. Submit a pull request with a clear description of your changes.

## Reporting Issues

If you find a bug or have a feature request, please open an issue with:
- A clear title and description
- Steps to reproduce (for bugs)
- Expected vs actual behavior

## Code of Conduct

Please review our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.
